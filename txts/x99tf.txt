第一步：先做基础状态排查
先确认WiFi硬件和系统服务的基础状态，定位故障根源。
执行命令 lspci | grep Network，查看系统是否能识别到无线网卡硬件。
执行命令 rfkill list all，检查WiFi设备是否被射频软锁定，执行 sudo rfkill unblock all 解除所有锁定。
执行命令 systemctl status NetworkManager，确认网络管理服务处于正常运行状态。
🛡️ 第二步：关闭BIOS中的Secure Boot
这是最常见的故障诱因，90%的同类问题都能通过这步解决。
重启电脑，在开机自检阶段按F2/F10/Del进入BIOS/UEFI设置界面。
找到Security选项卡，将‌Secure Boot‌选项设置为Disabled，保存设置后重启系统。
原因：NVIDIA驱动和部分无线网卡驱动属于第三方未签名模块，Secure Boot会直接拦截其加载，连带拖慢网卡固件初始化流程。
📦 第三步：补全缺失的内核模块包
安装显卡驱动时apt可能自动清理了无线网卡依赖的linux-modules-extra包，直接补装即可。
执行命令 sudo apt update，更新软件源索引。
执行命令 sudo apt install --reinstall linux-modules-extra-$(uname -r) linux-headers-$(uname -r)，重装当前内核对应的完整扩展模块包。
执行命令 sudo dkms autoinstall，强制DKMS工具为当前内核重新编译所有注册的驱动模块。
📶 第四步：重装对应品牌的无线网卡驱动
根据你的网卡品牌，针对性重装驱动，解决内核更新后的模块不兼容问题。
‌Intel网卡‌：执行 sudo apt install --reinstall firmware-iwlwifi，重装Intel无线网卡固件。
‌Realtek网卡‌：执行 sudo apt install --reinstall firmware-realtek，重装Realtek网卡驱动包。
‌博通网卡‌：执行 sudo apt purge bcmwl-kernel-source && sudo apt install bcmwl-kernel-source，清理旧驱动后重新编译安装。
🔄 第五步：重建系统固件缓存
如果前面步骤完成后WiFi仍未恢复，执行命令 sudo update-initramfs -u，更新系统启动时的固件镜像，确保无线网卡驱动能在开机阶段正常加载，最后重启系统即可。


UEFI+GPT配置正确，但依然黑屏（大概率是显卡驱动问题）‌
按下面步骤操作：
1.
‌临时进入系统‌：开机在GRUB菜单按e键编辑启动项，找到以linux开头的那一行，在末尾加上nomodeset，然后按F10或Ctrl+X启动。
2.
‌永久修复‌：进入系统后打开终端，编辑GRUB配置文件：
bash
sudo nano /etc/default/grub
找到GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"，改成GRUB_CMDLINE_LINUX_DEFAULT="quiet splash nomodeset"，保存退出，然后执行：
bash
sudo update-grub
sudo reboot
这样就能正常进桌面了。
3.
‌装显卡驱动‌：进桌面后，打开“软件和更新”里的“附加驱动”选项卡，选一个推荐的NVIDIA驱动版本安装，或者用命令行：
bash
sudo apt update
sudo apt install nvidia-driver-535
sudo reboot
装好后nvidia-smi能正常输出信息，就说明驱动OK了。‌‌
