到github上的项目的Settings --> Actions ---> Runners ---> New self-hosted runner，然后在Configure下拷贝类似如下命令：
./config.sh --url https://github.com/yuping420/test1 --token AZXR7VEIQN5J7YOET3LULETKL5CD2

nohup ./run.sh &
----这里要改成服务：
sudo ./svc.sh install
sudo ./svc.sh start
# 检查服务器状态，确保显示 active (running)
sudo ./svc.sh status
# 逆向操作：
sudo ./svc.sh stop
sudo ./svc.sh uninstall

在项目的.github/workflows/111.yml中的runs_on就可以配置为 self-hosted，如果加了多台，还可以单独指定：[self-hosted, server1]

删除runnuer：
./config.sh remove
然后会要求输入remove token，该token通过如下命令得到：
